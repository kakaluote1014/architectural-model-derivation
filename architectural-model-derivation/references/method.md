# 证据与镜头方法

## 用现有材料逐步理解

先看模型整体、对象树和单位/变换，再定位目标建筑、楼层与可见版本。检查屋面、墙体、开口、楼面、楼梯与廊桥的相邻关系。模型单独存在时，只描述观察到的空间构成；名称、功能或交通不明确就写“待核对”，不要求用户先填一套完整台账。

材料优先级：设计者当前明确决定 → 可核对的模型/尺寸/设计记录 → 来源标注的工作数据 → AI解释或建议。工作稿不能因成功展示而升级为已确认。合成几何只用于测试软件。

涉及模型写入时先复制，核对副本路径、修改状态与单位，再写入；避免覆盖现有人工修改。递归提取实例时累计父子变换，检查隐藏实体和标签、镜像实例的三角面绕序、继承材料及纹理缺失，选择当前可见版本，不拼入归档。SketchUp内部长度为英寸，不能直接当mm。保留原始导出并记录坐标公式、平移原点、轴变换、精度和哈希。

## 三种叙述不能混淆

模型解析的“整体→展开→局部→交通→归位”是**阅读顺序**，不是方案生成的真实历史。

过程还原需要每个阶段的日期、来源和设计者记录，区分同时存在的方案及被放弃的选择。缺失阶段不补造因果；证据不够时退回解析。v0.1可人工整理脚本，生成器尚不支持历史状态/多模型切换。

备选推演须由用户明确提出，先列固定条件、允许变化与比较标准，再在副本中制作实质不同的方案。AI提案和设计者采纳状态分开；不得偷偷改写当前模型。v0.1不包含此实现。

## 形成有依据的脚本

每章只回答一个空间问题，并注明依据和限制。常见顺序为定位→构成→代表空间→交通→整体，但章节数量和时长应随项目变化。不能依据通用住宅模板编造户型。

相机在同一坐标系内连续插值；重复关键帧提供观察停留。优先保持相似方位，让建筑贯穿章节；局部观察先检查遮挡和穿墙。镜头在手机窄画幅中也应保留目标。展开间距仅为展示距离，标高使用源模型值。标签与空间色块必须具有来源及身份。

有人的活动时，镜头顺着人物经过的入口、平台、楼梯和停留场所串联空间。可用完整案例的“整体定位→场所生活→分层→代表空间→走行→归位”作为叙事参考，但层数、章节、活动和时长按当前建筑配置。长路径按显示步速分配时间，不照搬旧案例48秒。人物到达室外后恢复适当的建筑材质和可见性，避免全程透明削弱空间理解。

时间轴以时间的纯函数计算完整状态；每次渲染都从原始顶点和基准材质重新赋值，不能增量累加位置或透明度。手动操作先暂停，在当前状态上覆盖；播放或跳章时清除手动覆盖。白模/材质对照保持时间、相机、可见性、透明度和几何不变，只切换表面颜色。
